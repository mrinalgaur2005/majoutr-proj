# Final major project submission pack

## Project

**Standard Load Profile-informed Support Vector Regression for short-term electricity load forecasting.**

Three connected parts, in this order:

1. **Load-profile characterization** — construction of daily profiles, peak-normalized grouping, and out-of-sample checks that the groups remain distinguishable on held-out meters.
2. **Short-term forecasting** — support-vector regression with profile-derived features, compared with persistence and other baselines on the residential evaluation cohort.
3. **Supplementary energy management** — illustrative time-of-day price exposure and battery procurement-cost evaluation on representative days. This application does not redefine the project.

Pattern groups are daily consumption regimes, not verified consumer categories. Tariff rates used in the storage study are illustrative sensitivity cases, not a utility schedule.

Academic writing for any new report or examiner text must follow the repository root files `CLAUDE.md`, `DOCUMENTATION_STYLE_GUIDE.md`, and `REPORT_GENERATION_CHECKLIST.md`.
